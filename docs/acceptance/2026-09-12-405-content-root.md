## 几何推导：内容区边界 = 内容 Column 顶边 538

1. **手柄槽 = [506,538]**：SmallSheetDragHandle 行高 12dp（SheetGestures.kt:48，12dp=31.5px）；像素探针证 sheet 视觉顶边=506（=槽顶）。
2. **48dp 触摸目标 = [459,585]**：dump 节点 [0,459][1080,585] 高 126px=48dp@420dpi，对 32px 槽上下各扩 47px≈18dp（459=506-47，585=538+47，完全对称）。
3. **内容 Column 顶边 = 槽底 538**：M3 sheet 布局 dragHandle 后紧接内容，无间隙。dump 佐证：Close 触摸容器顶 560 ≈ 538 + SpacingTokens.SM（8dp=21px，Spacing.kt:23）的行内留白；标题文本 592 起系其行内再排。
4. **行为互证**：实测分界 535 CLOSED / 541 VISIBLE（G-a），恰夹住 538；V2 探针 560/575 VISIBLE（位于容器节点 bounds 内但在内容侧）证明该 clickable 节点的 bounds 不等于拖拽消费区，有效收起区止于 538。
5. **源码 dp 互证**：SmallSheetDragHandle bar = top padding 5dp + 28×3dp（SheetGestures.kt:51-60）→ 换算 420dpi：条应在 y 506+13=519~527、x 503~577 —— 与像素探针实测（519~526 / 503~576）逐像素吻合。
