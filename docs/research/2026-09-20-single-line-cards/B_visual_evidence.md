## 一、对话视图：消息流形态（核心发现）

消息流不是「气泡卡片」流，而是**缩进行式日志流**（类似结构化 terminal/trace），仅用户消息是气泡。三种粒度：正文块 / 行摘要（reasoning、代码）/ 行摘要的子行（工具调用）。

### 1. 思考行（reasoning）
- 结构：`[图标] 思考 · <单行摘要…>`，DOM：`DIV._row_luwio_16.lcKema_row` → `_leading`（SVG 图标）+ `SPAN._title`「思考」+ `_sep`（圆点分隔）+ `_summary`。
- 图标：14×14 SVG，缠绕球形/思考标记，颜色 rgb(129,133,140)。
- 样式：标签 13px / lh 24px / w400 / **rgb(97,102,107)**（中灰）；摘要 13px / lh 20px / **rgb(129,133,140)**（更浅灰）；整行单行截断，尾部 `…`。
- 无折叠箭头、无边框无底色——与正文同层级直接平铺，仅靠灰度弱化。

### 2. 代码行（代码/run_code 步骤）
- 结构：`# 代码 · <单行摘要>`，`DIV._row_luwio_16.o3BgMG_row`；leading 是字面 `#` 字符（灰），不是图标。
- 标签/摘要与思考行同规格（13px，灰 97/129 系）；行高统一 24px 节奏。

### 3. 工具调用子行（挂代码行下）
- 结构：`[工具图标] 工具调用 · <工具名> · <参数摘要>`，同 `o3BgMG_row` 行组件。
- 视觉：**左侧竖线缩进**（浅灰 guide line，缩进约一个图标宽+树深），图标按工具变化：Bash=终端方框、编辑/写入=斜笔、读取=文档、工具调用=星芒形。
- 文件路径参数带**虚线下划线**（dotted-underline 链接样式）。

### 4. 状态色
- 正常摘要灰 rgb(129,133,140)；**错误行整体变红**：leading 换成红色实心圆点 ●，标签「代码」与 `Error: code run failed (exception): …` 摘要均为 **rgb(236,19,19)**（`o3BgMG_errorSummary`）；无红底，白底红字对比强。
- 进行中等待态：图标呈空心/时钟感（截图观察），配底部蓝色状态行「深度求索中… 10分26秒」。

### 5. 正文与用户消息
- 正文 16px 深黑 rgb(15,17,21)，关键叙述加粗；行内代码 chip：等宽 "SF Mono/JetBrains Mono/Fira Code" **12.25px**、底 rgb(250,250,250)、圆角 6px、padding 0 5px、border 1px rgba(0,0,0,.04)。
- 用户消息：**右对齐浅灰蓝圆角气泡**（消息流中唯一气泡），气泡下右对齐灰色时间戳 + 复制图标；助手内容全部平铺无气泡。
- 字体栈：-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC"…；页面纯白底 rgb(255,255,255)。
- 分页：顶部居中「加载更早」浅灰胶囊按钮（虚拟滚动，视口外消息卸载）。

### 6. 头部/底部框架
- 会话 header：标题 /「⠿ 70 个子代理 ˅」/「🐙 PTC 模式」/「1 个后台任务 ˅」+ 右侧模型选择；下方 Tab「对话 | 轨迹」，激活态蓝色文字+底部蓝条。
- 底部：大圆角输入框（+ / 麦克风 / 完全权限 / GLM-5.3 Max / 蓝色圆形停止键）+ 统计条「⟳ 157 轮 3383 步 · 147 tok/s · 979M tok · 缓存命中 99%」。

## 二、轨迹视图：另一形态（时间轴 + 表格）
- 顶部过滤器 chips：「时长 / 轮次 / 调用」+ 搜索框。
- **甘特式调用条形图**：模型行（蓝色方块序列）+ 工具行（橙色方块），失败调用红色方块，异类绿色方块标记；每方块≈一次调用，横向时间轴。
- 调用表格：每行 = 角色标签胶囊（「子工具」浅紫 /「工具」橙 /「助手」紫 /「用户」蓝 /「上下文」绿——颜色编码）+ 工具名 + 参数 JSON 截断 + `→` 结果摘要（失败红色 `CODE_RUN_FAILED`）；行首灰点为时间刻度。助手/用户文本消息以普通行混排其中。
- 表格行密集紧凑（约 24px/行），整页可承载数百行，是排查执行链路的视图；对话视图则是弱化中间过程的叙事视图。

## 三、关键视觉结论（供 oc-beacon 参考）
1. reasoning 用「灰度弱化的单行摘要行」呈现，不折叠、不占卡片——信息密度高、视觉噪声低；摘要 13px 双灰阶（标签 97,102,107 / 摘要 129,133,140）。
2. 工具调用是代码行的缩进子行，靠左竖线 + 图标语义化（终端/笔/文档）表达层级，无卡片边框。
3. 失败态 = 行级红色替换（红点 + 红标签 + 红摘要），无背景色变化。
4. 用户气泡是流中唯一气泡；助手侧全平铺——对话非对称布局。
5. 双视图策略：对话（叙事弱化中间步）↔ 轨迹（时间轴甘特 + 密集表格全量步骤），由 Tab 切换。
