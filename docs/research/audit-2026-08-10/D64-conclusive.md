# D64 决定性对照实验：backlog #64 超长消息会话滚动失效

**日期**: 2026-08-10
**结论**: **backlog #64 是误判（非 bug）**。滚动功能完全正常。
**根因**: 进入会话时 auto-scroll 到底部，"上滑"（手指上滑=看下方内容）在底部无内容可看，bounds 零变化是**正常行为**。

---

## 实验目标

判定超长消息会话（"调研harness记忆系统实践"，25 条消息，末条超长 AI 回复含 mermaid flowchart）滚动失效的根因：
- 假设 A：#41（MessagePaginationDelegate synchronized guard）回归
- 假设 B：固有 bug（D64 旧版"可滚"是超长消息未渲染完成的假象）

## 关键修正：原实验设计的逻辑漏洞

原实验（及之前所有二分实验 CURRENT/NO42/NO43/D64）只用 **swipe 上滑**（`540 1600 → 540 800`，手指上滑=看下方内容）测试滚动。
**但进入该会话时应用 auto-scroll 到底部**——在底部上滑，下方无内容，bounds 零变化是**正常的**，不代表滚动失效。
正确的滚动测试必须是**双向**的：下滑（看历史）+ 上滑（看下方），或确保不在边界测试。

## 实验 1：旧版 4c416fb1（完整无 #40-#43）+ 严格等 10s

| 步骤 | 结果 |
|------|------|
| worktree 检出 4c416fb1，构建安装 | OK（18s） |
| 进入会话，**严格等 10s** | 基线 dump 26990 字节，内容为会话**最底部**（可见总结段落、模型元数据 deepseek-v4-flash/46.9s、输入框） |
| 上滑 ×3（原实验方向） | 12 个节点 bounds **全部 dy=0**——但这是**在底部上滑**，正常无效 |
| **下滑 ×3**（看历史，修正方向） | **8 个历史消息节点新出现**（"二、我们独有而文章缺失的观点" y=[602,667] 等）→ **可滚** |

**旧版结论**：等 10s 后列表可向下滚动看历史。原 D64"可滚 -141px"不是加载未完成的假象，是真可滚（只是当时测错了方向）。

## 决定性对照：CURRENT 34092594 双向测试

为排除"假设 A（#41 回归）"，在 CURRENT（含 #40-#43 全部改动）上做双向测试：

| 方向 | 操作 | 结果 |
|------|------|------|
| 基线 | 进入会话等 10s | dump 26990 字节，与旧版基线**完全一致**（同在底部） |
| **下滑 ×3**（看历史） | `540 800 → 540 1600` | **10 个历史消息节点滚入**（"mega-hub 缺陷与概念中心范式" y=[1072,1174] 等）；底部标记 deepseek-v4-flash/46.9s **消失** |
| **上滑 ×3**（回底部） | `540 1600 → 540 800` | 历史消息节点**滚出**；底部标记 deepseek-v4-flash/46.9s **重新出现** |

**CURRENT 双向滚动均有效。与旧版行为一致。**

## 最终根因判定

| 候选 | 判定 |
|------|------|
| #41 回归 | **排除**——CURRENT 含 #41，下滑/上滑均正常 |
| #42 回归 | **排除**（此前二分已排除，本次再次确认） |
| #43 回归 | **排除**（同上） |
| 固有 bug | **排除**——双向滚动均有效 |
| **真相** | **#64 是误判**：进入会话 auto-scroll 到底，"上滑看下方"无内容可看，bounds 零变化是正常行为，被误读为"滚动失效" |

## 给 backlog #64 的处置建议

- 关闭 #64，标记为"误判（not a bug）"
- 误判根因：测试方法学缺陷——只在底部测上滑（单向），未做双向验证
- 教训：滚动类 bug 验证必须双向（上滑+下滑），并确认测试起点不在边界（顶部/底部）
