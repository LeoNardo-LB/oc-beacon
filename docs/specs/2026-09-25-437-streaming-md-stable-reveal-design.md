## 1. 问题定义

流式输出期间用户可见的闪烁/跳变，根因不在滚动引擎（#435 已封堵视口配对缺口），而在 **markdown 增量渲染把「尚未定案的解释」提前上屏**：不稳定尾部先按字面临时排版、闭合符号到达后回溯重释义 → 已显示内容高度回溯变化 → 跳变/闪烁。真机证据：录屏帧差分析显示同文本无新行、视口两态翻转（~350px 内容位移 @2-5Hz）；MDPilot 日志稳定/不稳定尾规模波动。

### 六层管线与跳变源（定罪表）

| 层 | 职责 | 跳变源 |
|---|---|---|
| L1 数据 | SSE→48ms 批→整串快照 StateFlow | 快照版本摆动（reconciler vs live 竞态）→ 状态重建风暴 |
| L2 派生 | 指纹缓存→renderableTurn | — |
| L3 状态 | pilot 前缀差分 append；非前缀→resetKey 整体重建 | 重建全量重解析 → 布局翻转 |
| L4 解析 | StreamingMarkdownFile：stableAst / unstableAstTail | **不稳定尾回溯重释义（主源）**；完结切 preParsedState+归一化=另一套布局（次源）|
| L5 布局 | Markdown() 全量渲染（stable+tail 一起画） | 上游喂什么排什么——回溯高度直接上屏 |
| L6 完结 | preParsedState 归一化+分片 | 完结瞬间一跳（代码自认的 V6 项）|

滚动引擎只能配对单调增长；本卡使命 = 把交给 L5 的高度流变成**单调量子增长**。

## 2. 核心方案：两级安全放行（safe-prefix gate）

**实施形态：在 pilot 的前缀差分与 state.append 之间加一道「安全放行闸」。库与渲染层零改动**——库收到的 append 流本身只含定案内容，库内 stable/unstable 分裂照常工作（作为第二道防线）。

```
48ms 批（整串快照）
  ↓ pilot 前缀差分 → 全量 delta
  ↓ 【新增】SafePrefixGate.release(snapshot) → 本批可放行前缀（纯函数）
  ↓ state.append(放行部分) → 库解析（stableAst 复用）→ 渲染 → ledger 配对
  └ 未放行尾部 → HeldTailBuffer（扣留区）
       ├ 超龄（>REVEAL_TAIL_AFTER_MS）→ 固定高度降亮纯文本区（高度锁定，内部变化不触布局）
       └ 毕业/完结 → 转正放行
```

### 放行规则（纯函数，JVM 可单测）

对一个快照文本 S，可放行前缀长度 = max（以下两级）：

**第一级：稳定块边界**。取库 stableAst 覆盖的文本长度（append 快照已暴露）——已闭合构造（强调/标题/围栏/表格/列表整体）全部放行。

**第二级：开放段落的安全后缀**（普通正文的低延迟通道——没有它，纯文字要等空行才出，不可接受）：
1. 定位最后一个开放段落（无空行终结的文本区）；
2. 段内扫描「活动标记」：`* _ ~ # > | [ ] ! -` 反引号 与有序列表起始（数字+.|)）——自段首起无任何标记字符 → 该段为纯文字段；
3. 纯文字段放行至**最后一个换行边界**（扣住最后一行——防 setext：下一批若出现 `---` 会把最后一行升格为标题）；
4. 段内出现标记字符 → 放行回退到该标记首现位置之前（其后全部扣住，等闭合）。

### 活性保障（不变量）

> 扣住的永远只是「差终止符」的尾部；去路恒两条——**毕业**（闭合→放行）或**完结**（completed 时间戳→全量 flush，EOF 按闭合解析，一字不丢）；超龄→降亮区保活。错误/中断/用户打断路径均写 completed（铁律 5 权威信号），天然覆盖。

- `REVEAL_TAIL_AFTER_MS = 300`（约 6 批）：尾部超龄进降亮区——锁高裁剪（转正放行时一次性扩张=一个配对量子）+ alpha 0.5 + 末尾呼吸光标。
- 超长代码块流中：降亮区持续累计，锁高刷新节流至每 500ms 一次（防每批重排）。

## 3. 与高度引擎（#435）的契约

- 放行流的高度变化 = 单调量子增长（毕业/转正/完结 flush）→ StreamingGrowLedger 照常同帧配对（锚即意图规则不变）。
- 降亮区高度恒定期间的内部重释义不产生任何布局事件（被裁剪）。
- 完结 flush 可能是单次大 Δ：增长→配对 ✓；若归一化（L6 切换）造成**收缩**→当前引擎不配对收缩——**阶段 C 处理**。

## 4. 数据层摆动（跳变源 L1/L3）——同卡范围

- 探测：pilot 内计数非前缀事件频率；>2 次/秒 → 记 FlapDetector 日志（MDPilot tag）。
- 抑制：resetKey 重建风暴限频（同文本 1s 内只重建一次，期间冻结放行）。
- 根因（reconciler vs live 双写竞态）若实证成立 → 另立数据层卡，本卡只做观测+止血。

## 6. 测试与验收

- **单测**：SafePrefixGate 判定表；超龄状态机；放行不变量（放行前缀单调不回退——除非非前缀重建）。
- **真机矩阵**：
  1. 纯文本长回复流式（贴底/尾段钉固/读历史三构型）——零跳变；
  2. 重 markdown 回复（表格+代码块+粗体混排）流式——成型瞬间无重排闪烁；代码块流中降亮区可见且锁高；
  3. 流中断连/报错——完结后内容完整（EOF 闭合验证）；
  4. 帧差录屏：无 A↔B 翻转签名（对照本轮基线证据）。
- **V6 人工项**：流式观感（纯文字体感应与现状无差；标记内容按块成型）。

## 7. 风险与回退

- 滞后风险：极端构造（整回复一个代码块）流中只见降亮区——有活性指示，可接受；完结全量。
- 放行规则误判 → 第二道防线=库 stableAst 分裂仍拦截；发现即补 gate 规则+用例。
- 回退：`STABLE_REVEAL_PILOT=false` 一行回到现状。
