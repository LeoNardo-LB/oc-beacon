## §二 #356 队列语义重构——调研腿（2026-09-08 午后）

**三服务器队列线缆全对称实证**（源码/OpenAPI 双证）：
- **DSH**（dsh-api-session-controller 源码）：session.prompt{requestId(V012),sessionId,content,mode:'queue'|'steer'}→{accepted:true}；steer=agent.steer()（尽力而为——窗口关闭自动转队列项）；queue=agent.followup()（inbox nextTurn 车道，轮末 claim 派发）。可见性=session/queue 控制帧（SessionQueuedItem{id,placement:queued|steering|context,rpcId?,message}，last-wins 整快照）；updateQueue edit/remove/steer。**持久回显**=user/message 事件 source={kind:'user',rpcId}（MessageSourceMap['user-rpc']）。
- **V2 beta-19086**（4199 OpenAPI 119 路径实测）：POST /prompt 带 delivery:'steer'|'queue'；GET /session/{id}/inbox（data:[Session.Inbox.Info oneOf User/Synthetic/Compaction/Move]）；DELETE /inbox/{id}（取消）；POST /inbox/{id}/queue|steer（双向转换，无 edit 动词）。SSE session.inbox.enqueued/delivered 已有映射。
- **V1**：prompt_async 无 delivery 参数（PromptPayload 10 字段无此键）——服务端默认内部排队，无可见域 → busy 菜单仅「立即发送」。
- **DSH web 客户端**（dsh-client-ui-chat/conversation 源码）：提交即渲染 PendingSubmissionBubble 本地 echo（steering 带 pending 样式），直到持久 user/steering 出现；**对账规则=observedRpcIds（持久节点 source.rpcId ∪ 队列项 rpcId）命中即隐藏 echo（原子换装）**。busy-Enter 策略：默认 queue，Cmd+Enter 反档。

**app 现状盘点**：V2 播种链（PromptAdmission→MessageUpdated 本地播种）+ 徽标机制（queuedMessageIds 位置派生：busy 期最后未完 assistant 之后的 user 消息→QUEUED CompactTag，Idle 清空）**均已存在**；DSH promptAsync 返回 null（无 echo——忙时消息不上屏的根因）；busy 菜单语义反了（立即发送=mode queue）；StackedMessageStore 本地排队（chips 条）需整体退役（服务端队列三面齐全后冗余）；SessionStateCollaborator.onNaturalTurnEnd 体已空（旧管线残留接缝，保留）。

**实现决策**：①DSH V012 prompt 受理后返回 PromptAdmission(id="pending-"+requestId) 走既有播种链；②mapUserMessage 读 source.rpcId→补发 MessageRemoved("pending-"+rpcId) 对账（幂等）；③busy 菜单反转：立即发送=steer/消息排队=queue（V1 仅前者）；④V2 prompt 带 delivery+inbox 三端点+queueSupported(V2) 翻 true+QueueSheet 复用（edit 动词按位隐藏）；⑤chips/StackedMessageStore 退役。
