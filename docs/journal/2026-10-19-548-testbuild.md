> 状态：交付待用户验收（2026-10-19）
> 关联卡：backlog #548（build/tooling）· 来源：卡片方案（2026-10-12 手工装机痛点）

## 1. 痛点与目标

每次 beta 测试包装机需人工判读 release-workflow §2 定规四件事：bare `-beta` 视为第 1 号→下一次是 `-beta-2`、`VERSION_CODE` 同步 +1、**先改 properties 再 assemble**、bump 是否落豁免域（纯序号递增免确认 vs 版本提升须确认）。2026-10-12 装 0.4.0-beta-2/42 即全程手工。

目标：`scripts/testbuild.sh <flavor> [serial] [--no-install] [--dry-run]` 一条命令免判定完成 bump→commit→assemble→装机→回读校验。

## 2. 设计定规

- **序号基准以 version.properties 为真相源**，tag 序号仅作防回退护栏（取 max 并 warn checkout 过时）。依据：本地测试包不发 tag，properties 领先 tag 是常态（当前 tag bare `v0.4.0-beta`=1 号，properties 已 beta-6/46）；release.sh 以 tag 为基准是发版即发 tag——两者语义互补不冲突。
- **越域一律拒绝并指回 release.sh**：stable flavor（正式发版）、dev 线→beta（通道晋升）、无预发布后缀（stable 线起点）——均属 2026-10-10 用户定规「版本提升须确认」域，本脚本只做纯序号递增豁免域。
- **dev 免 bump**：dev flavor versionCode 走 Unix 时间戳（build.gradle.kts 2026-08-13 决策），properties 不动、无 commit。
- **chore commit 只含 version.properties**：测试包常在开发中途打，不要求全树干净（warn 提示 APK 含未提交变更即可），`git add version.properties` 单文件绝不卷入。
- 装机段复用：miui-install.sh（push+pm install -r+MIUI 弹窗点穿，2026-08-21 已验证）、perf-session-scroll 的 wake+dismiss-keyguard 模式；serial 探测保留内嵌空格（mDNS 名，2026-10-10 journal §466 教训，禁 awk $1 截断）。

## 5. 实测发现的装置缺陷（2 起，当场根修）

- **a) miui-install.sh 裸调 adb**：本机 adb 在 `~/android-sdk/platform-tools/` 且 PATH/ANDROID_HOME 均无——testbuild 的 `ADB` 变量没传进子脚本，push 段「adb: 未找到命令」。修：miui-install.sh 支持 `ADB` 环境变量（缺省三级回退：ADB→PATH→SDK 惯例路径），内部 6 处 `adb -s` → `"$ADB" -s`；testbuild 调用处 `ADB="$ADB"` 透传。
- **b) testbuild.sh 自身 ADB 回退是字面量**：`$(command -v adb || echo adb)` 在 PATH 无 adb 时回退字符串 "adb"——轮 1 显式传 serial 绕过探测段+`|| true` 吞掉 wake 失败，掩盖到轮 2 才爆。修：`resolve_adb()` 三级回退（ADB 变量→PATH→ANDROID_HOME/ANDROID_SDK_ROOT/~/Android/Sdk/~/android-sdk 惯例路径→裸 adb 报错可见不静默）。
- 回归防护：两脚本 `bash -n` 过；干净环境（env -i + HOME）验证 resolve 链命中绝对路径。
